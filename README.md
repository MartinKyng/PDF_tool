# PDF Tool

PDF Tool is a focused desktop app for combining PDF files and turning pictures
into PDFs. It gives you a simple, modern drag-and-drop workspace and writes a
new PDF without editing the source files.

## What is included now

- Native desktop executable for Windows, macOS and Linux.
- **Join PDFs:** drag PDFs into the app, or use **Add** to choose them.
- **Images → PDF:** drop JPEG, PNG, BMP, GIF, TIFF or WebP files; each picture
  becomes one page of a new PDF.
- Reorder files before joining or converting.
- Live page counts and file sizes.
- Keep or remove bookmarks when joining PDFs.
- Choose an output folder and filename.
- Safe output handling: source files are never changed and an existing output
  is not replaced unless you explicitly enable overwrite.
- Work runs away from the UI thread, so the window stays responsive.

Splitting, rotating, deleting pages, annotations and other editor-style
operations remain out of scope for now.

## Install the desktop app

Download the latest **stable** release from the repository's GitHub Releases
page and choose the asset for your operating system:

- Windows: use `PDFTool-Setup-<version>-windows.exe` or the standalone app.
- macOS: use the macOS desktop executable. Code signing/notarisation is still
  planned.
- Linux: use the Linux desktop executable and make it executable if needed:
  `chmod +x PDFTool-<version>-linux`.

Beta releases are clearly marked as prereleases and are built from branches.
Use them for testing only; stable releases are built from `main`.

## Using the app

1. Open PDF Tool.
2. Choose **Join PDFs** or **Images → PDF** at the top.
3. Drop files into the list (or use **Add**).
4. Drag rows, or use the up/down controls, to set the output order.
5. Choose the output filename and folder.
6. For PDF joins, choose whether bookmarks should be kept. Optionally allow
   overwriting an existing file.
7. Select **Join PDFs** or **Create PDF**.

The app uses a page-level copy. It does not rasterise, re-typeset, resize or
recompress page content. Page geometry, rotation, resources, fonts and
embedded image data are preserved by the join engine. Encrypted PDFs are
reported as an error rather than decrypted.

## This is a desktop app, not a Python package

Python is used as the implementation language, but PDF Tool is distributed as
frozen native desktop executables. This repository intentionally has no Python
package metadata, no Python console entry point for end users, and no PyPI
publishing workflow. The Python modules are application source code bundled by
PyInstaller; they are not a supported importable library or pip package.

## Development

The build and test dependencies are only needed when working on the source (the
repository has no `pip install .` step):

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
QT_QPA_PLATFORM=offscreen python -m pytest
```

Run the development GUI directly:

```bash
python -m pdf_tool.gui
```

Build the local desktop executables:

```bash
python packaging/build_exe.py
```

The GUI and CLI launcher are bundled by `packaging/pdf-tool.spec`; the CLI is
kept as a small developer/automation companion, while the GUI is the product
and the release artifact users should install.

## Versioning and releases

There is one version edit point: [`pdf_tool/version.py`](pdf_tool/version.py).
Update `__version__` there using `MAJOR.MINOR.PATCH`, then merge the change to
`main` when it is ready. Do not edit workflow files or package metadata for a
version bump.

GitHub Actions handles the channels:

- A push to `main` builds Windows, macOS and Linux desktop artifacts and
  publishes a stable GitHub Release named `v<version>`.
- A push to any other branch builds a prerelease named
  `v<version>-beta.<run-number>`. The beta number is generated by CI, so
  branch builds never modify the version file.
- CI runs the test suite and headless GUI tests on every push and pull request.
- There is no PyPI release job. Desktop artifacts are the distribution.

See [`docs/RELEASING.md`](docs/RELEASING.md) for the maintainer checklist.

From the command line you can also convert pictures:

```bash
python -m pdf_tool --images photo.jpg scan.png -o album.pdf
python -m pdf_tool --images --separate photo.jpg scan.png -o album.pdf
python -m pdf_tool --images --separate --keep-names photo.jpg scan.png -o ./out
python -m pdf_tool --images --separate photo.jpg scan.png -o ./out --name cover.pdf --name inside.pdf
```
